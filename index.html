Methods and source library
Local TF–IDF cosine matching against four manually curated topic profiles. A fixed drafting rule uses the best matching card. Unmatched input gets a clarification prompt. Six jurisdiction contexts provide curated local references and inquiry routes. English vocabulary, single-topic ranking and a static policy snapshot limit coverage.
